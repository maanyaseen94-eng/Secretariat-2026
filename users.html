إضافة / تعديل موظف
هذي الصفحة تتحكم بصلاحيات المستخدم داخل التطبيق فقط. إنشاء حساب الدخول نفسه (البريد وكلمة المرور) لازم يصير أولاً من Firebase Console → Authentication → Users → Add user، وبعدها انسخ الـ UID الظاهر جنب الحساب والصقه هنا.
جهة وحدة بس = حقل "الى" يتعبى تلقائياً بيها ويصير مقفل. أكثر من جهة = يظهر للموظف قائمة اختيار يحدد منها الجهة عند انشاء كل كتاب.
ارفع صورة التوقيع (خلفية شفافة PNG أفضل) لمجلد signatures بمستودع GitHub تبع المشروع، وحط هنا اسم الملف بنفس الشكل. تظهر هذي الصورة مكان دائرة "ختم المكتب" بأي كتاب يسويه هذا الموظف، بدل الدائرة الفارغة.
